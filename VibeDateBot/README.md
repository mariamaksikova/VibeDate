# VibeDate

Dating-проект на Telegram-боте.

Стек: `aiogram` + `PostgreSQL` + `Redis` + `MinIO` + `RabbitMQ` + `Celery` + `Docker Compose`.

## Что уже работает

- регистрация пользователя через `/start`;
- заполнение анкеты (в т.ч. имя);
- редактирование отдельных полей анкеты;
- загрузка до 5 фото в профиль (ключ `tg:file_id`; MinIO в compose для дальнейшей интеграции);
- лента анкет с фильтрами;
- лайк/скип и мэтч с отправкой контактов;
- пересчёт рейтинга в таблице `ratings` + **периодический полный пересчёт через Celery Beat**;
- **Redis**: очередь до 10 заранее отранжированных `profile_id` на пользователя; при каждом показе карточка валидируется в БД, очередь дополняется (цикл как в ТЗ);
- **RabbitMQ**: события реакций в очередь `vibedate.profile_events` (потребитель: `python -m app.event_consumer`);
- **Prometheus**: счётчики ленты/реакций при `METRICS_PORT` (например `9100`);
- **structlog**: JSON-логи ключевых событий.

## Этап 4: запуск локально / на зачёте

```bash
cp .env.example .env
# заполнить BOT_TOKEN и при необходимости поправить DATABASE_URL
docker compose up --build
```

Сервисы:

| Сервис         | Назначение                          |
|----------------|-------------------------------------|
| `app`          | Telegram-бот                        |
| `celery-worker`| фоновые задачи (пересчёт рейтингов) |
| `celery-beat`  | расписание (раз в 10 минут)         |
| `db`           | Postgres (порт хоста **55432**)     |
| `redis`        | Celery + кэш ленты                  |
| `rabbitmq`     | очередь событий (UI **15672**)      |
| `minio`        | S3-совместимое хранилище            |

Тесты (без Docker, только формулы рейтинга):

```bash
PYTHONPATH=. python3 -m pytest tests/test_rating.py -q
```

Полный стек подтягивает `asyncpg` и удобнее на **Python 3.11** (как в `Dockerfile`).

## Ограничения и логика

- возраст пользователя: `18-100`;
- диапазон поиска: `18-100`;
- можно искать `м`, `ж` или сразу `м,ж`;
- username кандидата в ленте скрыт до мэтча.

## Описание проекта

VibeDate — приложение для знакомств в Telegram с механикой, близкой к реальным dating-сервисам. Пользователь регистрируется по `/start`, заполняет анкету, получает ленту кандидатов и ставит лайк или скип. При взаимном лайке создаётся мэтч, а рейтинг анкеты динамически пересчитывается на основе заполненности профиля и пользовательских реакций.
