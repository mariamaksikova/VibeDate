# VibeDateBot

Dating-проект на Telegram-боте.

Стек: `aiogram` + `PostgreSQL` + `Redis` + `MinIO` + `Docker Compose`.

## Что уже работает

- регистрация пользователя через `/start`;
- заполнение анкеты (в т.ч. имя);
- редактирование отдельных полей анкеты;
- загрузка до 5 фото в профиль;
- лента анкет с фильтрами;
- лайк/скип и мэтч с отправкой контактов;
- базовый пересчет рейтинга.

## Ограничения и логика

- возраст пользователя: `18-100`;
- диапазон поиска: `18-100`;
- можно искать `м`, `ж` или сразу `м,ж`;
- username кандидата в ленте скрыт до мэтча.

## Описание проекта

VibeDateBot —  приложение для знакомств в Telegram с механикой, близкой к реальным dating-сервисам. Пользователь регистрируется по `/start`, заполняет анкету, получает ленту кандидатов и ставит лайк или скип. При взаимном лайке создается мэтч, а рейтинг анкеты динамически пересчитывается на основе заполненности профиля и пользовательских реакций.
